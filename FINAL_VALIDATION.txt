BRAIN BACKUP CONTROL
--------------------
El payload está limitado a `memory.db`, `memory_export.json`, `profile.json`, `preferences.json`, `state.json`, `personality.py` y `config.json`. El manifest se genera solo después de confirmar cada archivo, el ZIP se reabre antes de devolver éxito y restore continúa rechazando extras, missing, traversal, duplicates, hash mismatch, schema desconocido y SQLite corrupta. La DB activa conserva WAL; el journal mode DELETE solo se usa en el snapshot temporal.

PACKAGE HYGIENE
---------------
El build usa allowlist explícita y falla ante archivos prohibidos en staging. La release incluye código, tests, tools, documentación, scripts, requirements, Flutter sources, `.env.example` y `.gitignore`. Excluye `.env`, `.git`, `.venv`, `__pycache__`, `*.pyc`, DB, WAL/SHM, logs, backups, audio, tokens, claves y datos privados.
