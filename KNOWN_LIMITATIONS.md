# GAIA-AI v1.0-RC6 Known Limitations

La validación Linux no demuestra funcionamiento físico de Windows 11, UI Automation, SMTC, audio, Ollama/Qwen local, GPU/VRAM, batería, temperatura, tres pantallas, LAN/TLS, Android/Flutter, firma ni sesiones prolongadas. Esos controles permanecen PENDING.

Las métricas de rendimiento dependen del entorno. Una diferencia menor al ruido estadístico se clasifica `INCONCLUSIVE`; no se usan umbrales universales entre hardware distinto. El benchmark no descarga modelos, no inicia Ollama y usa fixtures sintéticos acotados.

El paquete no contiene bases de datos, `.env` privados, tokens, logs, audio, capturas, modelos, APKs no verificados, keystores ni venvs. Los resultados privados se conservan fuera del árbol y fuera de los ZIPs.
